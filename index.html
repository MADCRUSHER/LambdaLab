How AWS Lambda works

Function

Code packaged for on-demand serverless execution.

Event

An event payload triggers an invocation.

Invocation

One request to execute a Lambda function.

Runtime

The execution environment, such as Python or Node.js.

CloudWatch

Lambda automatically sends invocation metrics and execution logs to CloudWatch.

API Gateway

Can expose Lambda through HTTP APIs.
